# Commits

- Mensaje resumido (1-2 líneas), en español, describiendo el qué/por qué — no un detalle línea por línea.
- Cuando el commit corresponde a una historia/incidencia, empezar con el ticket: `{{TICKET_PREFIX}}-XXX Descripción breve` (ver `git-flow.md`). Evitar mensajes genéricos como "Changes"/"Fix"/"Update"/"Cambios varios".
- Si una tarea implica varios cambios independientes, preferir commits separados.
- Nunca agregar línea de coautoría de IA (ej. "Co-Authored-By: Claude...") ni mención de que el commit fue generado por IA.
- Nunca hacer commit sin que el usuario lo pida explícitamente.
